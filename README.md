# nova-runtime

Experimental C++ realtime runtime used as a sandbox for multi-client session work:
core, renderer, audio, networking and scripting subsystems.

## Build

- Windows 10/11, x64
- Visual Studio 2022 (toolset v143)
- Open the solution under `src/` and build the desired configuration

## Layout

- `src/` — runtime sources (core, engine, render, sound, network, scripting)
- `res/` — resources

## Status

Work in progress. Interfaces and message formats are unstable and may change without notice.
