Every attempt exited with Windows exception `0xC0000005`; the log was zero bytes and no server port was ready. Windows Error Reporting gave executable RVA `0x1ff582`. The matching `10df37c24` DX11 CI executable (`SHA-256 0C23B5F4FB8FFDCC6F077A2E4BDEBDB2DB4A33C46656BD78B0DBDF86A20D510F`) passed the previous Lua fault and loaded the GAMMA scripts.
